Videos written in code open in the editor. Cuttle records your screen, or Claude Code at work, and edits the take itself: it cuts the waiting, zooms on what matters, masks your secrets and frames it into a demo you can post. Everything runs on your computer.

## Download

- **Windows:** `Cuttle-0.2.1-win-x64.exe`. It installs for you alone, without admin rights, with Start menu and desktop shortcuts. It is not code-signed yet, so SmartScreen may not know it: choose *More info*, then *Run anyway*.
- **macOS (Apple silicon):** `Cuttle-0.2.1-mac-arm64.dmg`. Open it and drag Cuttle into Applications. The first recording asks for the screen, the microphone, input monitoring and accessibility.

Cuttle also needs ffmpeg: `winget install Gyan.FFmpeg` on Windows, `brew install ffmpeg` on a Mac. Its first start says what is missing.

Cuttle 0.1.1 to 0.2.0 update themselves to this version within a day, or at once with *Restart and update* (Settings, General).

## New in this version

- **Videos written in code open in the editor:** a project of motion scenes, stills and cards needs no recording. `cuttle open` (or the MCP tool `open_in_editor`) shows it, and the editor follows every change Claude makes.
- **Room for the peaks:** an export at a platform's loudness stays under −1 dBTP after the AAC encoder, also with hard hits on every cut.
- **MCP:** `motion_add` names its page `src`, as every other tool and cuttle.json do.
