The room behind you, blurred, a colour or gone. Cuttle records your screen, or Claude Code at work, and edits the take itself: it cuts the waiting, zooms on what matters, masks your secrets and frames it into a demo you can post. Everything runs on your computer.

## Download

- **Windows:** `Cuttle-0.2.2-win-x64.exe`. It installs for you alone, without admin rights, with Start menu and desktop shortcuts. It is not code-signed yet, so SmartScreen may not know it: choose *More info*, then *Run anyway*.
- **macOS (Apple silicon):** `Cuttle-0.2.2-mac-arm64.dmg`. Open it and drag Cuttle into Applications. The first recording asks for the screen, the microphone, input monitoring and accessibility.

Cuttle also needs ffmpeg: `winget install Gyan.FFmpeg` on Windows, `brew install ffmpeg` on a Mac. Its first start says what is missing.

Cuttle 0.1.1 to 0.2.1 update themselves to this version within a day, or at once with *Restart and update* (Settings, General).

## New in this version

- **The room behind you:** the webcam shows you with the room blurred, a colour instead of it, or without it: only you, no bubble. A model finds you in each frame, on your computer; nothing is uploaded. In the bubble and in every camera layout: the Look tab → Camera → *Behind you*, or `cuttle webcam background blur`.
- **A Docker image:** each release puts one on GitHub's registry, `ghcr.io/lennystepn-hue/cuttle`, to render videos written in code on a server or in CI.
