Reading the screen works again on Macs where it stopped. Cuttle records your screen, or Claude Code at work, and edits the take itself: it cuts the waiting, zooms on what matters, masks your secrets and frames it into a demo you can post. Everything runs on your computer.

## Download

- **Windows:** `Cuttle-0.3.3-win-x64.exe`. It installs for you alone, without admin rights, with Start menu and desktop shortcuts. It is not code-signed yet, so SmartScreen may not know it: choose *More info*, then *Run anyway*.
- **macOS (Apple silicon):** `Cuttle-0.3.3-mac-arm64.dmg`. Open it and drag Cuttle into Applications. The first recording asks for the screen, the microphone, input monitoring and accessibility.

Cuttle also needs ffmpeg: `winget install Gyan.FFmpeg` on Windows, `brew install ffmpeg` on a Mac. Its first start says what is missing.

Cuttle 0.1.1 to 0.3.2 update themselves to this version within a day, or at once with *Restart and update* (Settings, General).

## Fixed in this version

- **"The screen could not be read":** on some Macs macOS stopped its accurate text recognition for Cuttle, and every take ended in this message after a long "preparing". Cuttle now reads with macOS's fast text recognition there, says so in a note (it misses more: still look yourself), and no longer prepares for a minute each time.
- A frame the text recognition cannot read is left out instead of stopping the whole read.
