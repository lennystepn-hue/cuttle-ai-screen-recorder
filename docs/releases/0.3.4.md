Recording with the computer's sound works again on macOS 27, and the HUD at the top of the screen casts a soft shadow. Cuttle records your screen, or Claude Code at work, and edits the take itself: it cuts the waiting, zooms on what matters, masks your secrets and frames it into a demo you can post. Everything runs on your computer.

## Download

- **Windows:** `Cuttle-0.3.4-win-x64.exe`. It installs for you alone, without admin rights, with Start menu and desktop shortcuts. It is not code-signed yet, so SmartScreen may not know it: choose *More info*, then *Run anyway*.
- **macOS (Apple silicon):** `Cuttle-0.3.4-mac-arm64.dmg`. Open it and drag Cuttle into Applications. The first recording asks for the screen, the microphone, input monitoring and accessibility.

Cuttle also needs ffmpeg: `winget install Gyan.FFmpeg` on Windows, `brew install ffmpeg` on a Mac. Its first start says what is missing.

Cuttle 0.1.1 to 0.3.3 update themselves to this version within a day, or at once with *Restart and update* (Settings, General).

## Fixed in this version

- **"The recording could not start. The screen capture stopped":** on macOS 27 a take with the computer's sound switched on failed at once, or hung while starting. macOS cut the picture's capture off when the sound's started beside it. They now run side by side.
- **A screenshot during a take** (Ctrl+Shift+Alt+C, or the HUD's camera) no longer ends the take on macOS 27.
- **The HUD's shadow:** at the top of the screen the HUD and the pill cast a shadow that the edge of their window cut into a grey box, on macOS and Windows. It is now soft, fades out before the edge, and has no dark outline.

## For Claude Code

- Claude plans a video written in code as a film before it writes a scene: the one idea, three storylines that differ, the first two seconds, the defaults a generated video falls into (a title card first, slides on a dark gradient, everything sliding up) and a review before the render. `cuttle mcp` has it as the guide topic `story`. The skill that Cuttle installed for Claude Code before keeps its older guides until it is installed again.
